# Product Steering — ML Playground

## Product Vision
Create an interactive ML education website where users can understand algorithms by changing parameters and watching the visualization react.

## Target Users
1. Recruiters reviewing the portfolio.
2. Students learning machine learning.
3. Lecturers or mentors who want to see the owner’s technical understanding.
4. Beginners who want visual explanations of ML algorithms.

## Main Value Proposition
The website makes abstract ML concepts visible:

- Linear Regression becomes a moving prediction line.
- K-Means becomes moving centroids and cluster assignments.
- Decision Tree becomes visible decision regions.
- Neural Network becomes changing decision boundaries.
- PCA becomes dimensionality reduction and variance projection.

## Product Tone
The product should feel:

- Educational.
- Technical.
- Clean.
- Portfolio-ready.
- Beginner-friendly.
- Professional enough for recruiters.

## Core Features
MVP features:

1. Algorithm selection page.
2. Interactive parameter panels.
3. Dataset generation.
4. Real-time visualization.
5. Metrics display.
6. Explanation panel.
7. Suggested experiments.
8. Responsive design.

Future features:

1. Dataset upload.
2. Export chart image.
3. More algorithms.
4. Blog/tutorial pages.
5. Compare algorithms.
6. Save experiment state.

## User Journey
1. User lands on homepage.
2. User reads project purpose.
3. User selects an algorithm.
4. User generates data.
5. User changes parameters.
6. User observes visualization.
7. User reads explanation.
8. User tries suggested experiments.
9. User opens GitHub or portfolio case study.

## Success Criteria
The app succeeds if users can understand at least one ML concept better after using the demo.

For portfolio success, recruiters should quickly see that the owner understands ML fundamentals and can build polished web-based tools.
