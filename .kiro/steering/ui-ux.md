# UI/UX Steering

## Design Goal
The app should look like a modern AI/ML lab, not a basic assignment project.

## Main Layout
Each playground page should use a three-zone layout:

1. Controls panel.
2. Visualization panel.
3. Explanation/metrics panel.

## Visual Style
Use:

- Clean cards.
- Rounded corners.
- Good spacing.
- Clear typography.
- Minimal colors.
- Smooth transitions.
- Professional icons.
- Responsive grid.

## Homepage UI
Homepage sections:

1. Hero section.
2. Short explanation.
3. Algorithm cards.
4. Why this project matters.
5. Tech stack badges.
6. Portfolio links.

## Algorithm Card Content
Each algorithm card should show:

- Algorithm name.
- Type: regression, clustering, classification, deep learning, dimensionality reduction.
- Difficulty level.
- What users can control.
- What visualization is shown.
- Button: Start Demo.

## Control Panel Rules
Controls should include:

- Clear labels.
- Slider values visible.
- Reset button.
- Generate dataset button.
- Run/step button.
- Short helper text.

## Explanation Panel Rules
Explanation should include:

- What this algorithm does.
- What the visualization means.
- What the current parameters affect.
- Suggested experiment.
- Limitation.

## Accessibility
Use:

- Good contrast.
- Keyboard-friendly controls where possible.
- Clear button labels.
- Avoid tiny text.
- Responsive layout.

## Responsive Behavior
Desktop:
- Three-column layout.

Tablet:
- Two-column layout.

Mobile:
- Stack sections vertically.

## Empty and Loading States
Even though the app is mostly client-side, show clear states:

- No dataset yet.
- Training not started.
- Converged.
- Reset complete.

## UX Principle
Every interaction should teach something.

If a user changes a slider, the app should make the effect visible and explain it.
